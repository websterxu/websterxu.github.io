# Webster Weichu Xu — Academic Website

Responsive, accessible static website based exclusively on the supplied CV. No build tools or third-party scripts are required.

## GitHub Pages
Create a public repository named `websterxu.github.io`, upload index.html, styles.css, script.js, and .nojekyll to the main branch. In Settings → Pages, choose Deploy from a branch, main, / (root), and enable HTTPS. GitHub provides the final published address.

## Content
All biographical and academic content is sourced from the supplied CV. Its stated dates and “to appear” statuses are preserved. Mobile phone number and immigration status are excluded. The original CV is deliberately not included in this public website package.
